# Diario in bici

App web per registrare le uscite in bicicletta: GPS, velocità, km, mappa del percorso, foto e note lungo la strada, statistiche, parziali per km ed esportazione GPX.

Indirizzo: https://gsimoneschi-spec.github.io/diario-in-bici/

- I dati (uscite e foto) restano solo nel browser del telefono che li registra; dalle Opzioni si può esportare e reimportare un backup.
- Il tracciamento funziona con la pagina aperta e in primo piano.
- Mappe © OpenStreetMap, CyclOSM, OpenTopoMap; libreria Leaflet.
